This project is a C-based multi-stage rocket delta-v calculator, designed to estimate the total change in velocity for a rocket using Tsiolkovsky Rocket Equation. 
This project allows you to: 
1. Input multiple rocket stages
2. Enter mass and engine data for each stage
3. Compute the exhaust velocity,idividual stage delta v, and the total mission delta v.
4. Automatically skip invalid inputs.
